# Roadmap

Where Atelier is heading next. This is a direction, not a promise of dates; plans change as we learn. Product behaviour is
specified in [docs/design](docs/design/), and the [issues](https://github.com/3SENN/atelier/issues) track the details.

## Next

- **More model choices.** Run the companion on local models and OpenAI-compatible providers as well as Anthropic, so
  anyone can try Atelier without a paid API key.
- **Signed builds everywhere.** Signed Windows installers, and a dedicated update channel for official builds.
- **Linux packages.** First-class packages for the major distributions.
- **Packs ecosystem.** Better tools for making, testing and publishing packs, apps and companions, and a richer
  community index.

## Later

- Accessibility review of every surface, with screen readers on each platform.
- More languages beyond English and Dutch.
- Optional, privacy-preserving ways to use Atelier across devices.

## Where help is especially welcome

- **Translations:** new languages and reviews of existing ones (`src/shared/i18n/`).
- **Platform testing:** Windows and Linux in particular.
- **Packs, apps and companions:** build something for Atelier and share it in the
  [community index](https://github.com/3SENN/atelier-packs).
- **Documentation:** guides, examples and corrections.
- **Issues labelled** [`good first issue`](https://github.com/3SENN/atelier/labels/good%20first%20issue) and
  [`help wanted`](https://github.com/3SENN/atelier/labels/help%20wanted).

Have an idea? Start a [discussion](https://github.com/3SENN/atelier/discussions).
