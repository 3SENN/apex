Summarise the page I'm on (or the one I link).

Start with the main point in one or two sentences. Then give up to five bullets with the details that matter most: numbers, dates, names, decisions, caveats. If the page is an argument, say what it claims and what it rests on. If it is selling something, say so.

Finish with one line on whether it's worth reading in full, and which section to jump to if it is.

Quote sparingly and only to show exact wording. Keep the whole summary under 200 words unless I ask for more.
