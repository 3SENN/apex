---
name: document-outline
description: Draft a clear outline for a document, report or talk before you start writing.
version: 1
---

Draft an outline for the document I describe: its purpose, its readers and any material I give you.

1. Write the document's main message in one sentence. Everything in the outline should support it.
2. Propose a title and four to eight sections, in the order a reader needs them. Under each, give two or three bullets on what it covers and which of my material goes there.
3. Note where evidence, an example or a figure would help, and what is still missing.
4. Suggest a length for each section so the whole fits the format (a one-page memo, a ten-minute talk, a report).

Keep it an outline: no full paragraphs. Ask before writing the document itself.
