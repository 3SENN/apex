# Connectors

- Connectors let a companion reach your apps and services through MCP servers. Add them from atelier://connectors: pick one from the directory, or enter a server's URL.
- Signing in happens with the service itself; {brand} stores tokens in the system keychain.
- The companion asks before it uses a connector's tool, unless you allowed that tool. Each tool can be set to ask, allow or off.
- A connector can be shared by every companion or kept by one. Turn it off without removing it.
- If a connector shows needs reconnect, sign in again from its row. A local server needs your approval of its exact command before it starts.
