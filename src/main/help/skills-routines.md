# Skills and routines

- A skill is a saved set of instructions. Type /name in a chat to use one. {brand} ships a few built-in skills (such as page-summary, compare-options, research-brief and weekly-review); duplicate one to change it.
- Save as skill turns a chat into a draft skill you can edit before saving. Skills can be shared with every companion or kept by one.
- A routine runs a prompt on a schedule: daily at a time, every few minutes or hours within a window, on a cron expression, or once. Each run is a background chat you can open later.
- Routines can be paused, run now, and edited at apex://routines. Routines installed from a guide arrive paused so you can review them first.
- A routine's run never controls your open tabs; it works in the background with the tools you allowed.
