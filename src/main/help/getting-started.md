# Getting started with {brand}

- {brand} is the browser you make your own. It comes with a companion: open a chat with ⌘J (Ctrl+J elsewhere), from the new tab's composer, or from the sidebar.
- The companion can read the page you're on, open tabs of its own, click, type and fill forms. Its tabs carry a small mark, and it asks before anything that matters, such as buying, sending, posting or deleting.
- Describe a skill, a routine or a small app and the companion builds it with you. Packs (apex://packs) carry what you make to other people: New pack… starts one in a chat with a companion, Share as pack… sends a skill, site tweak, app or companion you already have, and Browse lists what others have shared. Every install shows what a pack can do before anything is added.
- Setup can be run again from the profile menu (Getting Started). The getting-started page (apex://first-week) has a checklist of first steps and short guides.
- Guides (apex://guides) explain the main features and can install a ready-made bundle of skills and routines.
- Settings live at apex://settings. Every page has a short description at the top.
- {brand} runs on your own Claude access: an Anthropic API key stored in the system keychain.
- Keyboard: ⌘L focuses the address bar, ⌘T opens a tab, ⌘\ splits the view, and right-clicking a link offers a peek.
