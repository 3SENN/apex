# Memory and connectors

Your companion gets more useful the more it knows about what you care about, and the more of your tools it can reach. Memory and connectors are how.

## Memory

Your companion keeps short notes as it learns things you'd want remembered: your home city, how you like summaries, which airline you fly. It writes them as plain files you can read and edit at any time.

- Open a companion's card and choose the **Memory** tab to see its notes.
- Shared notes, which every companion can read, are in [Settings › Memory](apex://settings/memory).
- Ask in any chat: "What do you remember about me?" or "Forget my old address."

Memory never stores passwords or payment details.

## Connectors

A connector links your companion to another app, like a calendar, notes or a project tracker, so it can look things up or make changes when you ask. {brand} uses the open MCP standard, so any compatible server works.

Add one in [Connectors](apex://connectors). Choose whether every companion can use it or just one. Your companion always tells you when it uses a connector, and asks first before anything it changes.

> Tip: try "What's on my calendar tomorrow?" once a calendar is connected.
